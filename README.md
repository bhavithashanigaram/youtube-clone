# YouTube Clone 

A simple **YouTube homepage clone** created while practicing **HTML and CSS**.
The project focuses on recreating the basic layout and visual structure of YouTube using only frontend fundamentals.

##  Features

* YouTube-inspired homepage layout
* Navigation sidebar
* Header with search bar
* Video cards
* Video thumbnails
* Channel information
* Video titles and metadata
* Responsive layout practice
* Clean and organized CSS

##  Technologies Used

* **HTML5**
* **CSS3**

##  Purpose

This project was created as a **practice project** to improve my understanding of HTML and CSS.

Through this project, I practiced:

* HTML5 semantic elements
* CSS Flexbox
* CSS Grid
* Positioning
* Spacing and alignment
* Search bar design
* Navigation layouts
* Video card layouts
* Responsive design

##  How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

You can also use **Live Server** in VS Code for a better development experience.

##  Project Status

This project is created for **HTML and CSS practice** and is not connected to the actual YouTube platform.
